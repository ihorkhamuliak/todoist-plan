# todoist-plan

[English](README.md) | **Українська**

План дня, який живе в Todoist і з'являється у двох місцях: на робочому столі Windows (віджет Rainmeter)
і на старті кожної сесії Claude Code (короткий бриф). Зроблено для однієї людини, яка щоранку питала
«який план на сьогодні?» замість того, щоб просто робити.

**Todoist знає «що і коли». Нотатки знають «чому і як».** Опис кожної задачі вказує на розділ нотаток
із контекстом, тож план лишається коротким, і нічого не губиться.

## Що отримуєш

```
БАЗОВЕ: Оплатити інтернет (−2 дн) · Зарядка · Англійська  ← особисті задачі згорнуті в один рядок
СЬОГОДНІ
◐ Сесія з клієнтом · ще 3                                ← ● P1  ◐ P2  ○ P3, «ще 3» = відкриті підзадачі
   ↳ 19:20 Надіслати фоллоу-ап
ВТ 06.10
● Тест 10 подач (Бот v1)
закрито сьогодні: 2 · без дати: 4 · оновлено 08:00       ← закрито сьогодні, без дати, останнє оновлення
```

Написи англійською (`"lang": "en"`) або українською (`"lang": "uk"`), задається в `config.json`. Назви задач лишаються такими, як ти їх написав.

- **Прострочене + сьогодні + 3 дні.** Повторювані задачі теж вважаються простроченими: пропущений рахунок лишається пропущеним.
- **Робота детально, особисте одним рядком**, тож звички й побутові справи видно, але вони не витісняють роботу вниз.
- **Журнал закритого.** На кожному оновленні віджета нові закриття дописуються в Markdown-журнал у нотатках,
  тож нотатки знають, що зроблено, навіть якщо їх тиждень ніхто не відкривав.
- **Ніколи не порожній план, що виглядає справжнім.** Без мережі чи з проблемою токена видно останній знімок і рядок ⚠️.

## Встановлення (Windows, ~15 хв)

```
py -m pip install todoist-api-python keyring httpx
copy config.example.json config.json            # мова, робочий проєкт, виключені проєкти, шлях до журналу
py save_token.py                                # після того, як скопіював API-токен у Todoist
py todo.py brief
```

**Віджет:** встанови [Rainmeter](https://github.com/rainmeter/rainmeter/releases), далі
- скопіюй `rainmeter/PlanDay/@Resources/paths.example.inc` у `paths.inc` і впиши три шляхи;
- підключи скін: `New-Item -ItemType Junction -Path "$env:USERPROFILE\Documents\Rainmeter\Skins\PlanDay" -Target .\rainmeter\PlanDay`;
- увімкни: `Rainmeter.exe !ActivateConfig "PlanDay" "PlanDay.ini"`, потім `!ZPos "-2" "PlanDay"`, щоб він жив на
  робочому столі, і **Win+D** показував його миттєво;
- за бажанням гаряча клавіша: ярлик у меню Пуск на `Rainmeter.exe !ToggleConfig "PlanDay" "PlanDay.ini"` з полем Shortcut key
  (Windows обробляє такі клавіші із затримкою 1-5 с).

Скін запускає `todo.py widget` при старті й кожні 5 хвилин (близько 36 запитів до API на годину, ліміт 1000 за 15 хвилин).
Клік відкриває апку Todoist на «Сьогодні».

## Команди

| | |
|---|---|
| `todo.py brief [--folder NAME]` | план + закрите за 3 дні (+ усі задачі секції, прив'язаної до NAME), з id |
| `todo.py widget` | пише `widget.txt` для скіна й оновлює журнал |
| `todo.py done [--days N]` | що закрито, повтори теж |
| `todo.py list [--section S] [--days N]` / `find TEXT` / `show ID` | подивитись |
| `todo.py add "TEXT" --section S [--due "Oct 6"] [--parent ID] [--p 1-3]` | нова задача, мітка `claude`, за замовчуванням P3 |
| `todo.py close ID` | закрити |

## Пастки Todoist API, на які ми наступили (жовтень 2026, API v1, SDK 4.0)

1. **Дедлайни лише в Pro**: `deadline_date` на Free повертає 403 `PREMIUM_ONLY`.
2. **`@слово` вирізається з назви** як мітка навіть з `auto_parse_labels=False`. `add` прибирає знак `@`.
3. **Закрита підзадача лишається закритою**, коли повторювана батьківська переходить на наступну дату, тож чек-листи під повторами працюють один раз.
4. **Час із фіксованим поясом приходить в UTC**: «31 жовтня 00:00 Europe/Warsaw» приходить як 30 жовтня 23:00. `split_due` зсуває.
5. **Повтори не видно в списку закритих задач** (вони переносяться, а не закриваються). Журнал активності їх бачить,
   із затримкою в кілька секунд.
6. **`TodoistAPI(token)` без змінної** закриває HTTP-клієнт ще до першої сторінки.

## Тести

`py -m unittest discover -s tests`. Планування й рендер це чисті функції на синтетичних задачах, без мережі.
